# ADR 0002: Corrective workflow for Proposal A

Date: 2026-10-04

## Context

Occurrence pre-analysis has a fixed retrieval, evidence assessment, bounded correction, and structured-output sequence.

## Decision

Use a deterministic workflow with bounded correction; reserve autonomous tool selection for Proposal B.

## Consequences

Workflow runs are easier to trace and evaluate. The workflow graph and generation nodes remain to be implemented.
